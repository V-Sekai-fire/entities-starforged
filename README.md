# entities-starforged

The design for a game demo whose one native binary is both the interactive game and the video head that records it.

## What it is for

An avatar framed like a video call offers the planner's legal moves at each decision point, and the chosen move's outcome drives its expression. The same binary walks a shot list and records it, so the video is the game recorded. RFD 1175 in `manuals-weftspun` owns the design.

## Build and run

The repository holds no code, so there is nothing to build.
